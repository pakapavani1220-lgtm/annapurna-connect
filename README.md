## 🔗 Live Demo
**Website:** https://papaya-zabaione-40a6c0.netlify.app

## ✨ Features

### Advance Admin Dashboard
- Live tracking of all donors, NGOs, logins
- Real-time statistics & analytics
- Food waste management
- User management

### Donor Module
- Donate food easily
- Track donations
- Login & dashboard

### NGO Module
- Receive donations
- Manage requests
- Distribution tracking
